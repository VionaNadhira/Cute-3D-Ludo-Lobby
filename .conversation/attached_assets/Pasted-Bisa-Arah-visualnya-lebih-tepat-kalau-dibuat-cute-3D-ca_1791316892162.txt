Bisa. Arah visualnya lebih tepat kalau dibuat **cute 3D cartoon board game**, dengan karakter chibi, warna cerah, material glossy, dan UI yang terasa seperti game mobile Jepang/Korea. Jangan menyalin aset karakter atau layout spesifik LINE Get Rich, tetapi ambil karakteristik visualnya.

Buat sebuah **web game Ludo modern dengan visual 3D cartoon / cute board game**, terinspirasi dari kualitas visual game mobile Korea/Jepang seperti game board character-collection, tetapi **jangan menyalin karakter, aset, logo, layout, atau elemen spesifik dari LINE Get Rich**.

Untuk tahap pertama, **hanya buat Home Screen / Main Menu**. Jangan membuat gameplay Ludo terlebih dahulu.

Tujuan utama:

> Home Screen harus terasa seperti game mobile premium yang penuh karakter, bukan website yang memiliki game.
